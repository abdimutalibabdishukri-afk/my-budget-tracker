# My Budget Tracker

## About the Project

My Budget Tracker is a simple website created using HTML and CSS. It helps users view and organize their expenses.

## index.html

The index.html file contains the structure of the website.

It includes:

* Budget Tracker heading
* Logo image
* Add Expense form
* Expense name input
* Amount input
* Category dropdown
* Date input
* Add Expense button
* Expense table
* Sample expense data
* How to use section
* Budgeting video

## style.css

The style.css file controls the appearance of the website.

It includes:

* Page background and text styling
* Form styling
* Table borders
* Colored table header
* Alternating table rows
* Table hover effect
* Input focus effects
* Button styling
* Video section styling
