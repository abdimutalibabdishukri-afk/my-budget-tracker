# My Budget Tracker

## Description

My Budget Tracker is a simple web application for recording and viewing personal expenses.

## Files

- index.html - Contains the structure and content of the Budget Tracker.
- style.css - Contains the visual design and styling.
- README.md - Explains the project and its files.

## Features

- Add an expense name
- Enter an expense amount
- Select an expense category
- Select a date
- View expenses in a table
- Clean and simple user interface

## Technologies Used

- HTML
- CSS
